# Gravar o GIF da arena 3D

O README usa `docs/arena3d.gif` (cerca de 800 px de largura, abaixo de 1 MB). Para atualizar:

1. `python web.py --host 127.0.0.1 --port 8000`
2. Crie a sala com dois jogadores e marque **Co-op contra chefe**.
3. No tabuleiro, clique **Arena 3D**, escolha o chefe como alvo.
4. Grave 4 a 6 segundos: gire a câmera arrastando o canvas e, se der, ataque.
5. Exporte GIF em loop, recorte a barra de rolagem e substitua `docs/arena3d.gif`.
